# ResNet-20 RTL Handoff Contract

This document records R0.5 F6b: ResNet-20 RTL handoff contract closure.  It
freezes the numerical and operator contract for the next INT8/INT32 export
package.  It does not modify RTL/testbench, start RTL R1, or generate final
memh, task sequence, or `1 MB` memory reuse map assets.

## 3. Frozen Numerical Contract

Rounding:

```text
round_half_away_from_zero
```

Saturation:

```text
signed INT8 clamp [-128, 127]
```

Requant:

```text
clamp(round_half_away_from_zero(acc * multiplier / 2^shift), -128, 127)
multiplier: positive int32-compatible integer
shift: 0..31
```

Weight quantization:

```text
INT8 per-tensor symmetric signed quantization
per-channel quantization: not implemented in v1
```

Activation quantization:

```text
INT8 per-tensor symmetric signed quantization
input layout: HWC
input quantization: uint8_minus_128
```

Folded bias:

```text
folded_bias = beta - running_mean * gamma / sqrt(running_var + eps)
bias_int32 = round_half_away_from_zero(folded_bias / accumulator_scale)
accumulator_scale = input_activation_scale * weight_scale
storage dtype = signed INT32
Conv ordering = output channel order
FC ordering = output neuron order
```

GAP:

```text
input: INT8 activation tensor after final residual block
operation: sum 8x8 spatial region per channel in INT32
divide by 64: fixed shift / reciprocal contract, no hardware divider
output: INT8 vector length 64
```

Residual ADD:

```text
main branch -> target_add_scale
shortcut branch -> target_add_scale
INT32 aligned add
ReLU
requant to post_relu_scale
signed INT8 clamp
```

## 6. Decision

F6b allows the project to enter F6c INT8/INT32 export package generation.  That
next stage may generate export assets, but this F6b stage did not generate them.

RTL R1 remains not started.  Any RTL implementation must preserve existing
LeNet/HB/AXI/NPU contracts and must not reinterpret this document as permission
to change current requant semantics, shared memory layout, store packing, or the
single-task register-triggered control model.
